# Samir Sharif - Portfolio

Modern portfolio built with **Vite + React + TypeScript** and CSS Modules.

## 🚀 Quick Start

```bash
cd frontend
npm install
npm run dev
```

App starts on **http://localhost:3000**

## 📁 Structure

```
frontend/
├── src/
│   ├── main.tsx              # Entry point
│   ├── App.tsx               # Main component
│   ├── data.ts               # Portfolio data
│   ├── types/index.ts        # TypeScript types
│   ├── styles/globals.css    # Global styles
│   └── components/
│       └── Header/
│           ├── Header.tsx
│           └── Header.module.css
```

## 🎨 Styling

- **CSS Modules** for all components
- Global variables in `styles/globals.css`
- No Tailwind

## 📝 Customize

Edit `src/data.ts` for your portfolio data.

## 🛠 Tech

- Vite + React 18 + TypeScript
- Framer Motion, Lucide Icons
- CSS Modules
